Entry for the [The Funniest Honest Appliance Error](https://make.fun/c/u-xvader-the-funniest-honest-appliance-error-adec4450) bounty on make.fun — one line, at most 200 characters: the funniest honest error message an appliance could show.

## The entry

> Error E04: load unbalanced. I redistributed the laundry three times. It is still unbalanced. I am walking across the laundry room now. Goodbye.

143 characters. `main.py` writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) — directly to the final file, no temp files, no trailing newline.

## Run

```sh
python3 main.py
```
